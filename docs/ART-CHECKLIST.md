# 插畫檢查清單（v2.12.1）

方法：以 180px 大圖聯絡表逐張目視 242 張 SVG（`tools` 外的目視部分無法自動化），再用 `node tools/audit.js` 做自動檢查。
判準：①一眼看出是什麼、用途；②配件位置合理；③數量與名稱一致（複數＝多個）；④比例合理；⑤不怪異。

## 自動檢查（tools/audit.js）
- 離線快取清單涵蓋所有 js/data/css
- 同一張圖只在一個檔案定義
- 每個單字的圖都存在
- 場景：不出界、不與小怪獸重疊、高度 10–62%
- 數字卡 0–10 圓點數＝數字
- 「數一數」選項不使用帶圓點的數字卡
- 執行無 JS 錯誤

## 尚未能驗證
實體手機／平板的觸控與視覺大小；幼兒是否「一眼看懂」（需真人試用）。
