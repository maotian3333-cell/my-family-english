# My Family English v2.0

家庭專屬英文輔助教學網站（家長提示工具）。純 HTML / CSS / JavaScript，沒有後端。

## 直接使用
雙擊 `index.html` 即可在電腦瀏覽器開啟（資料檔是 `.js`，所以不需要伺服器）。

## 放上 GitHub Pages
1. 在 GitHub 建立新儲存庫（免費版需為 Public）。
2. 上傳整個資料夾內容。
3. Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save。
4. 幾分鐘後會得到網址，手機和電腦都能開。

## 圖卡
139 張圖卡全部是自繪 SVG（`data/art.js`），風格統一。

## 加到手機主畫面（離線）
網站放上 GitHub Pages（https）後，用手機瀏覽器開啟，選「加到主畫面」即可，之後沒網路也能開。更新網站內容後，請把 `sw.js` 裡的 `VERSION` 改成新編號，使用者才會收到新版。雙擊 `index.html` 直接開啟時不會啟用離線功能（瀏覽器限制）。

## 孩子模式
首頁右上角 👶 進入。孩子看到的是圖示地圖，玩「聽一聽點一點」；沒有計分、沒有失敗，點錯只會再聽一次。右上角 🔒 要解家長鎖才能離開，使用時間在 ⚙️ 設定（5／10／15 分鐘或不限）。

## 字母聲音（階段 C）
瀏覽器內建語音只會唸字母名稱，不是發音，所以請你自己錄：⚙️ 設定 → 字母聲音 → 🎙 錄音（需要 https，例如放上 GitHub Pages 後；錄音只存在該裝置，不會上傳）。也可以自備音檔，命名為 `s.mp3`、`a.mp3`… 放進 `audio/phonics/` 資料夾一起上傳（記得把 `sw.js` 的 `VERSION` 改成新編號）。

## 隱私
- 孩子的紀錄、筆記只存在**你的瀏覽器**（localStorage），不會進入儲存庫。
- 不要把孩子的姓名、照片、錄音放進儲存庫。
- 換裝置不會同步：請在「設定 → 匯出備份」定期備份，到新裝置用「匯入備份」。

## 學習單 PDF
`worksheets/` 內有 54 份（18 單元 × 3 年齡）。修改 `data/worksheets.js` 後執行 `bash tools/build-pdfs.sh`（需 Chrome）重新產生。

## 完整重建規格
見 `docs/REBUILD-SPEC.md`。

## 新增教材
- 短語：編輯 `data/phrases.js`。
- 單元教材卡：編輯 `data/lessons.js`，複製一個 `{ id: "A9", ... }` 區塊修改。

## 家長鎖
進入設定：點右上角 ⚙️，解一元一次方程式（例如 4x + 1 = 9，求 x）。
