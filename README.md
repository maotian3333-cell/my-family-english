# My Family English v1.0

家庭專屬英文輔助教學網站（家長提示工具）。純 HTML / CSS / JavaScript，沒有後端。

## 直接使用
雙擊 `index.html` 即可在電腦瀏覽器開啟（資料檔是 `.js`，所以不需要伺服器）。

## 放上 GitHub Pages
1. 在 GitHub 建立新儲存庫（免費版需為 Public）。
2. 上傳整個資料夾內容。
3. Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save。
4. 幾分鐘後會得到網址，手機和電腦都能開。

## 隱私
- 孩子的紀錄、筆記只存在**你的瀏覽器**（localStorage），不會進入儲存庫。
- 不要把孩子的姓名、照片、錄音放進儲存庫。
- 換裝置不會同步：請在「設定 → 匯出備份」定期備份，到新裝置用「匯入備份」。

## 新增教材
- 短語：編輯 `data/phrases.js`。
- 單元教材卡：編輯 `data/lessons.js`，複製一個 `{ id: "A9", ... }` 區塊修改。

## 家長鎖
進入設定：點右上角 ⚙️，解一元一次方程式（例如 4x + 1 = 9，求 x）。
