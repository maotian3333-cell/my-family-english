# My Family English v2.3

家庭專屬英文輔助教學網站（家長提示工具）。純 HTML / CSS / JavaScript，沒有後端。

## 直接使用
雙擊 `index.html` 即可在電腦瀏覽器開啟（資料檔是 `.js`，所以不需要伺服器）。

## 放上 GitHub Pages
1. 在 GitHub 建立新儲存庫（免費版需為 Public）。
2. 上傳整個資料夾內容。
3. Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save。
4. 幾分鐘後會得到網址，手機和電腦都能開。

## 圖卡
139 張圖卡全部是自繪 SVG（`data/art.js`），風格統一。

## 加到手機主畫面（離線）
網站放上 GitHub Pages（https）後，用手機瀏覽器開啟，選「加到主畫面」即可，之後沒網路也能開。更新網站內容後，請把 `sw.js` 裡的 `VERSION` 改成新編號，使用者才會收到新版。雙擊 `index.html` 直接開啟時不會啟用離線功能（瀏覽器限制）。

## 孩子模式
首頁右上角 👶 進入。孩子看到的是圖示地圖，玩「聽一聽點一點」；沒有計分、沒有失敗，點錯只會再聽一次。右上角 🔒 要解家長鎖才能離開，使用時間在 ⚙️ 設定（5／10／15 分鐘或不限）。

## 字母聲音（階段 C）
瀏覽器內建語音只會唸字母名稱，不是發音，所以請你自己錄：⚙️ 設定 → 字母聲音 → 🎙 錄音（需要 https，例如放上 GitHub Pages 後；錄音只存在該裝置，不會上傳）。也可以自備音檔，命名為 `s.mp3`、`a.mp3`… 放進 `audio/phonics/` 資料夾一起上傳（記得把 `sw.js` 的 `VERSION` 改成新編號）。

## 隱私
- 孩子的紀錄、筆記只存在**你的瀏覽器**（localStorage），不會進入儲存庫。
- 不要把孩子的姓名、照片、錄音放進儲存庫。
- 換裝置不會同步：請在「設定 → 匯出備份」定期備份，到新裝置用「匯入備份」。

## 學習單 PDF 與互動版
每個單元 3 版（內容相似、題目順序不同），在網頁上按「🖨 列印」即可輸出（也可選「三版一起」一次印三頁、或存成 PDF）；列印時會自動隱藏按鈕與導覽，只輸出 A4 學習單。專案不再附 PDF 檔。同樣的題目也有互動版（`#act/單元/版本`）。

## 2 到 6 歲課程
2 歲聽與玩（Z1–Z5）→ 3 歲生活短句（A1–A9）→ 4 歲單字與句框（B1–B6）→ 5 歲字母聲音與押韻（C1–C8）→ 6 歲拼讀與閱讀（D1–D6）。每個年齡有自己的內容與題型。

## 完整重建規格
見 `docs/REBUILD-SPEC.md`。

## 新增教材
- 短語：編輯 `data/phrases.js`。
- 單元教材卡：編輯 `data/lessons.js`，複製一個 `{ id: "A9", ... }` 區塊修改。

## 家長鎖
進入設定：點右上角 ⚙️，解一元一次方程式（例如 4x + 1 = 9，求 x）。

## 大量練習
- 互動版有「隨機練習」（`#act/單元/r`）：每次從題庫抽新題、題數加倍，不限次數。
- 每個年齡有「綜合複習」（RZ／RA／RB／RC／RD），混抽前面學過的單元。
- 每個詞有 3 個例句輪流用；字母單元每個字母有 3～9 個例字；拼讀單元每組 6～7 個字。

## 多元活動（v2.3）
不只一種練習方式。同一單元的 3 版會用不同的活動，紙本與互動版共用同一份題目：
賓果、找一找（圈出所有一樣的／字母搜尋）、字母轉盤與 CVC 字族轉盤、換字頭（只換開頭子音）、連點成圖（5、6 歲 a 到 z，4 歲 1 到 10）、字母迷宮、照字母塗色、大小寫配對、開頭音分類、泡泡字塗色、補字母順序；字母與拼讀單元另有「直接教學頁」（`#sheet/單元/t`、`#act/單元/t`）：先示範、再一起、最後自己做。
程式在 `js/kinds.js`，各單元的活動組合在 `data/practice2.js`。

### v2.8 直接教學（C1–C6、D1–D3）
練習教的是「聲音／結構」而不是單字：先示範正例、再對比反例，然後做 ✔/✖ 判斷題；每回合正反例的數量、比例與順序固定（4:2、4:4、4:6），規格見 docs/REBUILD-SPEC.md 8.2 第 4e 項。程式在 js/di.js。

### v2.8 完整字母與語音結構
字母 a–z 全部涵蓋（C1–C6、C9–C11）；拼讀結構涵蓋 CVC（D1–D3）、雙字母 sh/ch/th（D7）、混合音（D8）、魔法 e（D9）、兩個母音（D10）、r 控制母音（D11）。規格在 data/phonics.js，出題邏輯在 js/di.js。

### v2.8 易讀性
學習單一律白底，文字用黑／藍／紅；字母格改成白底彩框同色字；字級加大。原則記在 docs/REBUILD-SPEC.md 8.2 第 4g 項。

### v2.8 版面簡化
標題直接寫要學的內容（ar / or / er ir ur…），拿掉字母框與例子大框，只用顏色與色條分組。見 docs/REBUILD-SPEC.md 第 4h 項。
